#  About

Athr Portfolio
This project is a **React + Vite** application that showcases immersive storytelling for Saudi Arabia’s heritage and culture.  
It includes animated background transitions, region highlights, and cinematic intro sections built with **Framer Motion**.


---

#  Prerequisites

Before running the app, make sure you have the following installed:

- **Node.js**: v18 or later (LTS recommended)  
  [Download Node.js](https://nodejs.org/)  

- **npm**: comes with Node.js (v9 or later recommended)  
  Check versions:

  ```bash
  node -v
  npm -v

#  Quick Start

Clone the repository:  
`git clone https://github.com/sulimanalkhunaizan/Athr-Protofolio.git`  
`cd athr-portfolio`

Install dependencies:  
`npm install`

Run the app:  
`npm run dev`

The app will be available at: 
👉 http://localhost:5173
